# BGRemover — Built By NoMaD

Remove a solid-color background (green, blue, red…) from a video and export a **WebM with real transparency**.

**Use it:** https://nomad-wolf-clan.github.io/bgremover/

1. Tap **Open video** and choose a clip (MP4 or WebM).
2. The backdrop color is detected automatically. Use **Pick background** to sample it exactly.
3. Tune **Tolerance, Softness, Choke, Despill** until the edges are clean.
4. **Export WebM**, then **Download .webm**.

Everything runs in your browser. Videos are never uploaded.
Export works best in Chrome or Edge (desktop or Android).
